7. What is async and await? 
--> async:- Placed before a function to mark it as asynchronous,
     meaning it will always return a Promise (or Task).

    Await:- : Pauses the execution of the async function until a background operation finishes,
     allowing the main program to stay responsive.

            Benefits
                Cleaner syntax
                Easier error handling
                Avoids callback chaining

                EX:- async function fetchUserData() {
                try {
                    // await pauses execution until the promise resolves
                    const response = await fetch('https://example.com'); 
                    const userData = await response.json();
                    console.log(userData);
                } catch (error) {
                    // Errors are cleanly handled using standard try/catch blocks
                    console.error("Error fetching data:", error); 
                }
            }
