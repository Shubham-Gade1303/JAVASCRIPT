5. What is event bubbling?
---> Event bubbling is a machanism where an event start at the target element and propragate upword through 
    its parent element
    Event bubbling means an event propagates from the target element to its ancestors in the DOM hierarchy.

    Ex:- Button → Div → Body → HTML → Document
    document.getElementById("child")
        .addEventListener("click", () => {
            console.log("Button");
        });

        document.getElementById("parent")
        .addEventListener("click", () => {
            console.log("Div");
        });




6. What is event delegation? 
---> Event Delegation uses a parent element to manage events for multiple child elements.

        Advantages:- 

        Better performance
        Less memory consumption
        Supports dynamically added elements

        Instead of:
        button1.addEventListener(...)
        button2.addEventListener(...)
        button3.addEventListener(...)

        Use: - 
        parent.addEventListener(...)

        it has no expiry

        ex:- 

        localStorage.setItem("name", "Shubham");

    sessionStorage:- 
        Data exist onlky while the browser tab reamains open
